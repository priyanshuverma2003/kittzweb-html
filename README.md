# Kirti4Arts | Premium Art Gallery

Discover unique originals, prints, and sketches by Kirti Verma.

## 🚀 Live Demo
Check out the live application here: **[https://kittzweb-html-sz65.vercel.app/](https://kittzweb-html-sz65.vercel.app/)**

## ✨ Features
- **Premium Art Gallery**: A curated collection of original artworks with lightbox zooming.
- **Mobile Optimized**: Fully responsive design with a glassy mobile menu and staggered animations.
- **Admin Panel**: Easily add new artworks with automatic HTML generation and backend integration.
- **Shopping Cart**: Functional add-to-cart system with WhatsApp checkout integration.
- **Search System**: Real-time search with keyboard navigation and recent history.
- **Instagram Integration**: Floating widget to follow the artist's latest updates.

## 🛠️ Technology Stack
- **Frontend**: HTML5, Vanilla CSS3, JavaScript (ES6+)
- **Backend**: Node.js, Express
- **Database**: MongoDB (via Mongoose)
- **Deployment**: Vercel

## 📦 Installation & Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/priyanshuverma2003/kittzweb-html.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Set up environment variables:
   Create a `.env` file and add your `MONGODB_URI`.
4. Run locally:
   ```bash
   npm run dev
   ```
